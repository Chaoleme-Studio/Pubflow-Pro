# Alipay Embedded Materials

This folder is for local build-time Alipay materials. Files here are ignored by git,
but `app/build.rs` reads them during `cargo build` and embeds their contents into the
backend binary.

Recommended filenames:

- `app_private_key.txt`
- `app_public_key.txt`
- `alipay_public_key.txt`
- `app_cert_sn.txt`
- `alipay_root_cert_sn.txt`

The build script also accepts the filenames generated by Alipay's key tool:

- `应用私钥RSA2048-敏感数据，请妥善保管.txt`
- `应用公钥RSA2048.txt`
- `alipayPublicKey_RSA2.txt`

Optional certificate files, if you want the SDK to derive certificate serial numbers:

- `appCertPublicKey.crt`
- `alipayRootCert.crt`
- `alipayCertPublicKey_RSA2.crt`

After the binary is built, the server does not need this folder.

If only the three key TXT files are embedded, the SDK still needs certificate serial
numbers. Plain key TXT files do not contain certificate issuer/serial metadata, so the
SN values cannot be derived from them.

Use one of these two options:

- Put `app_cert_sn.txt` and `alipay_root_cert_sn.txt` in this folder so they are embedded
  into the binary too.
- Or set `ALIPAY_APP_CERT_SN` and `ALIPAY_ROOT_CERT_SN` in `.env`.

The SN values can be left empty only when the app public certificate and Alipay root
certificate `.crt` files are also embedded.
