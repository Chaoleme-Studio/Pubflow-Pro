# PubFlow 授权保护方案 v2

> 本文档已被 v3 总方案取代：[`licensing-protection-design-v3.md`](../licensing-protection-design-v3.md)

v2 的核心问题是：授权签名使用客户端可派生的 HMAC 密钥，密钥藏在 WASM 中。这个方案可以提高逆向成本，但授权根基仍在客户端，不适合作为商业授权的最终方案。

v3 的主要变化：

- 从“客户端 HMAC 验证”改为“服务器私钥签名，客户端公钥验签”。
- 从“浏览器指纹机器码”改为“Native Helper + 系统稳定 ID + 设备密钥对”。
- 从“永久离线为主”改为“短期 lease + 离线宽限为默认，同时支持永久买断证书”。
- 从“缓慢降级”改为明确授权状态和错误提示。
- 将代码保护、选择器加密、WASM、授权、机器绑定、永久离线统一到一份总设计文档。
