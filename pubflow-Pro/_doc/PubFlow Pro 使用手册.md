# PubFlow Pro 使用手册

## 一、安装插件

1. 下载并解压 PubFlow Pro 插件包。
2. 打开 Chrome 或 Edge，在地址栏输入 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择刚刚解压后的插件文件夹。
   - 如果压缩包里有多层目录，请选择包含 `manifest.json` 的那一层。
6. 安装成功后，浏览器右上角会出现 PubFlow Pro 插件图标。

## 二、首次设置

1. 点击浏览器右上角的 PubFlow Pro 图标，打开 Dashboard。
2. 进入“设置”。
3. 在“主工作区”里点击“选择文件夹”。
4. 选择一个本地文件夹作为工作区。
   - 建议单独新建一个文件夹，例如 `PubFlow工作区`。
   - 插件会把草稿、素材引用、发布记录和项目数据保存在这里。
5. 浏览器弹出授权提示时，点击允许。

## 三、激活授权

1. 仍然在“设置”页面，找到“授权保护”。
2. 在“激活码”输入框里粘贴你的激活码。
3. 点击“激活并验证授权”。
4. 页面显示“已授权”或“授权有效”后，即可开始使用。

说明：订阅版需要定期联网验证授权。正常发布时只会在点击“开始发布”前做一次授权检查，发布过程中不会反复打断。

## 四、登录发布平台

发布前，请先在当前浏览器里登录你要发布的平台账号。

目前支持的平台包括：抖音、小红书、视频号、B站、快手、微博、知乎。西瓜视频当前为预留配置，暂不在发布入口开放。

建议先手动打开目标平台确认账号已登录，避免发布时跳到登录页。

## 五、创建发布内容

1. 打开 PubFlow Pro Dashboard。
2. 进入“发布”页面。
3. 选择发布类型：
   - 发布视频
   - 发布图文
   - 发布文章
4. 根据内容类型填写信息。

发布视频时：

1. 点击“选择视频文件”。
2. 填写标题、简介、话题。
3. 可选：选择封面、配乐、定时发布时间。

发布图文时：

1. 点击“选择图片”。
2. 第一张图片会默认作为封面。
3. 填写标题、简介、话题。

发布文章时：

1. 编辑文章标题和正文。
2. 按需要插入图片或整理 Markdown 内容。
3. 填写摘要、话题等信息。

## 六、选择目标平台

1. 在发布页右侧找到“目标平台”。
2. 勾选要发布的平台。
3. 如果某个平台不支持当前内容类型，页面会自动过滤或不可选。
4. 如需设置平台专属选项，可以点击对应平台标签查看个性化设置。

## 七、开始发布

1. 确认内容、素材、平台都已选择完成。
2. 点击“开始发布”。
3. 插件会先进行一次授权检查。
4. 授权通过后，插件会自动打开第一个平台的发布页。
5. 页面打开后，插件会自动上传素材并填充标题、简介、话题、封面等内容。
6. 一个平台处理完成后，可以继续处理下一个平台。

注意：平台页面不会强制自动提交发布。填充完成后，请用户自己检查内容，再按平台页面上的发布按钮确认。

## 八、侧边栏查看进度

发布过程中可以打开浏览器侧边栏查看平台队列。

侧边栏会显示：

- 当前正在处理的平台
- 已完成的平台
- 失败的平台
- 等待处理的平台

如果某个平台失败，可以根据提示检查页面是否登录、素材是否上传成功、平台页面是否改版。

## 九、发布记录

1. 进入 Dashboard 的“记录”页面。
2. 可以查看历史发布任务和平台结果。
3. 如果更换浏览器或重装插件，只要重新选择同一个工作区文件夹，就可以继续读取本地工作区里的数据。

## 十、常见问题

### 1. 加载插件时找不到文件夹

请确认已经先解压插件包，并选择包含 `manifest.json` 的目录。

### 2. 点击发布后提示授权失败

请进入“设置”，确认激活码是否正确，并点击“激活并验证授权”。如果授权已过期或被解绑，请联系购买渠道处理。

### 3. 平台页面打开后没有自动填充

请检查：

- 当前浏览器是否已登录该平台。
- 页面是否停留在平台的发布页。
- 是否允许插件访问该网站。
- 平台页面是否有弹窗、登录验证或风控验证需要先手动处理。

### 4. 上传素材失败

请检查：

- 视频或图片文件是否还在本地原路径。
- 工作区是否仍有权限。
- 文件格式是否被平台支持。
- 文件大小是否超过平台限制。

### 5. 换电脑、重装浏览器或清理浏览器数据后怎么办

重新安装插件后：

1. 重新选择原来的工作区文件夹。
2. 在设置里重新输入激活码并验证。
3. 如果提示旧设备占用，可以到卡密自助服务里解除旧设备占用，或联系支持处理。
