# PubFlow v1.2.0 发布说明

**发布日期：** 2026-07-18
**版本号：** 1.2.0
**标签：** `v1.2.0`

## 主要更新

### 新增平台支持

- **X（Twitter）视频发布**
  - 自动打开 `https://x.com/compose/post`，复用浏览器现有登录状态。
  - 上传本地视频，按 280 个 Unicode 字符限制组合标题/描述/话题文案。
  - 支持设置回复权限（所有人可回复 / 仅关注者 / 仅提及的人）。
  - 等待附件状态明确显示“就绪”后才标记完成。
  - 最终发布按钮保留给用户手动确认。

- **YouTube 视频发布**
  - 从 Studio 首页直接打开上传弹窗，必要时回退“创建 → 上传视频”。
  - 自动填写标题、描述、话题、观众、年龄限制、AI 披露、付费宣传、标签、语言、类别、自动功能、嵌入、通知等个性化设置。
  - 自动经过“视频元素”“检查”并停在“公开范围”，支持公开/不公开列出/私享/公开定时日期和时间。
  - 在频道权限允许时尝试上传自定义封面，等待真实预览变化后才报告成功。
  - 最终发布/保存/预定按钮保留给用户手动确认。

### 其他功能增强

- 视频号个性化设置新增“视频标注”（无需标注 / AI 生成 / 虚构剧情 / 个人观点 / 营销广告）。
- 发布视频窗体支持直接拖入视频文件，并增加文件类型校验、拖入状态提示和错误反馈。
- 封面区域支持整卡点击选择、拖入图片以及连续选择同一个文件进行替换。
- 新增 `4:3`、`3:4`、`9:16`、`16:9` 四种封面预览比例；默认选中 `4:3`。
- 未选择封面时，发布页使用视频首帧作为本地预览，但不会生成封面文件或向平台上传封面。
- 发布记录新增“待确认（filled）”状态、最近状态更新时间以及从记录继续填充或重试的入口。
- 新增浏览器级可信拖拽能力 `CDP_DRAG`，用于知乎 `ReactCrop` 竖屏裁剪框定位。
- 新增草稿、授权恢复和视频记录合并测试。

### 修复与稳定性

- 修复 X 视频仍在上传时任务提前进入已填充的问题。
- 修复 YouTube 未完成手机号验证时封面错误显示为已上传的问题。
- 修复同一个视频文件多次发布时被文件名去重、导致“我的视频”始终只有一条记录的问题。
- 修复发布完成后草稿媒体引用未清理的问题。
- 修复插件重新加载后第一次发布可能提示 `Invalid token` 的问题。
- 修复从单条发布记录继续或重试时同时选中其他未发布平台的问题。
- 修复激活码被全部隐藏或脱敏文本可能进入编辑状态的问题。
- 修复小红书、视频号、知乎竖屏封面流程中的多处 DOM 兼容性问题。
- 修复 YouTube 年龄限制、高级设置、Shorts 混剪权限、定时公开范围等交互竞争问题。

### 工程与发布

- 移除 X/YouTube 收费 API 直发、OAuth 账号连接、专用上传进度和失败重试代码。
- 清理旧 X/YouTube API 直发架构文档和 Publisher 空目录。
- 建立 `Changelog/` 目录，归档每个版本的完整发布说明。
- GitHub Release 自动读取根目录 `CHANGELOG.md` 并打包构建产物。
