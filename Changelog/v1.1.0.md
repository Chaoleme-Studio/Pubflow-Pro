# PubFlow v1.1.0 发布说明（归档）

**发布日期：** 2026-07-13
**版本号：** 1.1.0
**标签：** `v1.1.0`

> 此版本是 v1.1.0 的发布记录快照。后续版本继续维护根目录 `CHANGELOG.md`，发布时 GitHub Actions 会自动读取根文件并打包，无需为每个版本修改工作流。

## 主要内容

- 视频与封面拖入、封面整卡点击、默认 `4:3` 和四种预览比例。
- 多次发布独立记录、旧媒体清理、授权恢复和激活码局部脱敏修复。
- 右侧任务抽屉打开顺序、Dashboard 打开后收回抽屉等交互优化。
- 小红书、视频号、知乎竖屏封面流程兼容。
- X 与 YouTube 网页自动填充，复用浏览器现有登录态，不依赖收费 API、OAuth Client ID 或 Publisher Service。
- X 自动打开原生发帖页并上传视频；YouTube 进入 Studio 后优先直点“上传视频”，必要时回退“创建 → 上传视频”，最终发布仍由用户确认。
- X 等待视频状态真正进入“就绪”并支持回复权限；YouTube 补齐观众必填项和常用个性化设置，封面需确认预览成功且账号应先完成手机号验证。
- YouTube 年龄限制会先展开高级选项再填写；视频号新增“视频标注”个性化设置和页面自动选择。
- YouTube 会点击真正的“展开 / 显示高级设置”按钮并等待 Shorts 混剪权限渲染，不再误认按钮内部触摸反馈层。
- YouTube 高级设置改为等待目标混剪选项，并将自定义缩略图上传提前；可选高级项异常会提示手动检查，不再跳过封面或让整个任务失败。
- YouTube 自动走完三个“继续”步骤并填写最终公开范围或定时时间，但保留“发布 / 保存 / 预定”给用户手动确认。
- YouTube 定时发布改为串行完成 `PUBLIC` 公开范围，等待状态稳定后再切换互斥的“安排时间”区域。
- YouTube 定时发布固定公开的规则会在发布设置和任务结果中明确展示，其他可见性仍用于非定时发布及其他平台。
- 平台个性化标签只跟随当前勾选的平台，旧草稿设置不再导致知乎入口莫名出现。
- GitHub Release 自动读取根目录 `CHANGELOG.md` 并打包构建产物。
